# Pac-Xon source

Install cc65, Python, Java, and Kick Assembler. Put the command-line tools on your PATH. Set the KICKASS_JAR environment variable to the full path of KickAss.jar. From this folder, run the following in PowerShell.

~~~powershell
.\build.ps1
~~~

The game builds to `release/pacxon.prg`.

The Studio 256 intro is included as the PRG used by the release packer.
