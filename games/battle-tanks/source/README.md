# Battle Tanks source

Install cc65, Python, Java, Kick Assembler, and Exomizer. Put the command-line tools on your PATH. Set the KICKASS_JAR environment variable to the full path of KickAss.jar. From this folder, run the following in PowerShell.

~~~powershell
.\build.ps1
~~~

The game builds to `build/battletanks.d64`.
