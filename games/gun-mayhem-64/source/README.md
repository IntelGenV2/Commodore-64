# Gun Mayhem 64 source

Install cc65, Python with Pillow, Java, and Kick Assembler. Put the command-line tools on your PATH. Set the KICKASS_JAR environment variable to the full path of KickAss.jar. From this folder, run the following in PowerShell.

~~~powershell
.\build.ps1
~~~

The game builds to `build/gunmayhem64.d64`.

Original Gun Mayhem by Kevin Gu and the original team. The menu theme is “Black Signal” by Original C64 Menu Sessions.
