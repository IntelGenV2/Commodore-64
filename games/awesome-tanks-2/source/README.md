# Awesome Tanks 2 source

Install cc65, Python with Pillow and py65, Java, Kick Assembler, Exomizer, and c1541 from VICE. Put the command-line tools on your PATH. Set the KICKASS_JAR environment variable to the full path of KickAss.jar. From this folder, run the following in PowerShell.

~~~powershell
.\build.ps1
~~~

The game builds to `release/tanks.d64`.

The Studio 256 intro is included as the PRG used by the release packer.
